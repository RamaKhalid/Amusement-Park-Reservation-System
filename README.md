
# 🎢 Amusement Park Reservation System

A Java-based application for managing amusement park reservations.

## ✨ Features

* Manage customers
* Manage amusement park attractions
* Create and manage reservations
* View reservation information

## 🛠️ Built With

* Java
* Object-Oriented Programming (OOP)
* NetBeans

## 📚 About

This project was developed to practice **Java and Object-Oriented Programming** by building a simple reservation system based on a real-world amusement park scenario.

## 🚀 How to Run

1. Clone the repository.
2. Open the project in **NetBeans**.
3. Build and run the project.
